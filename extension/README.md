# 腾讯会议纪要存档

> v1.4.1：课堂反馈新增中文/英文选项，默认中文并记住上次选择，其他案例诊断提示词不变。先发布网站更新，再重新加载新版插件。

1. 解压 ZIP。
2. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择含 manifest.json 的文件夹。
4. 安装后刷新已打开的课堂档案页面，并把插件固定到工具栏。
5. 首次使用：在顶部「mooodle 账号」填写教师账号和密码，点「保存并登录」。登录成功时状态栏显示「已登录 mooodle」并变为青色，账号栏标题变成「已登录 · mooodle 账号：xxx」；账号或密码错误时显示红色原因，账号栏保持展开。
6. 以后打开插件会自动登录，状态栏显示「已自动登录 mooodle」并直接读出当天课次；登录失效时显示红色原因，重新填写密码即可。
7. 自行登录腾讯会议，打开纪要，点击原页面的复制按钮。
8. 点击插件「读取标题」，核对左上角课堂名称，可直接修改为学生/课堂关键名字；点击「读取已复制纪要」并核对全文。
9. 日期默认北京时间当天，可修改；点击「匹配当日课次」优先匹配学生/课堂名字，忽略大小写、空格和标点；多个候选须手动选择。
10. 读取或粘贴纪要后，在「反馈语言」选择「中文」或「English（英文）」，点击「生成课堂反馈」。AI去除会议标题、发言人等格式，按具体案例分析能力薄弱点、可能原因和针对性巩固建议，并保留原文提及的通用技巧；不补充不存在的课堂事实。语言选择只改变输出语言，其他提示词保持不变，生成中不能切换语言。生成会消耗工作区credits，费用随纪要和输出长度变化；仅教师和管理员可用。
11. 生成时可点击「停止生成」，关闭弹窗也会停止；原纪要保持不变。核对可编辑的反馈预览，点击「使用此反馈」将其用于存档，或点击「复制反馈」。使用后可「恢复原纪要」。生成不会自动写入学生档案，未完成结果不可使用。
12. 点击「存入选定课堂总结」，确认正确日期、时间、学生后追加保存。评分选填：已有评分仅修改填入项目，知识点进度追加；无评分时自动新建，未填项目按网站默认值。
11. 当前课堂评分按学生+日期保存。同一学生同日多课时禁止插件直接保存，需到学生档案核对后手动处理。没有关联学生档案的班课不会列入存档选项。
12. 原有「仅准备纪要」及课堂评分内「导入会议纪要」仍可用。标题读取选择器需在真实腾讯会议页面验证，读错时手动修改。正式网站必须先更新发布才能使用最新版插件的读取与存档接口。

密码只保存在本机浏览器插件的本地存储中，不同步；登录时发送给账号登录服务验证，不发送给AI。不用时可点「清除账号」。插件不接收腾讯会议密码或 Cookie，不读取录制视频。只有主动点「生成课堂反馈」才将纪要发送至 Lovable AI 并消耗credits，复制、预览及存档不调用AI。草稿、原文与反馈保存在本机，24小时后下次打开清除，可随时点「清除纪要」。
