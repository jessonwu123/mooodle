# 腾讯会议纪要存档

1. 解压 ZIP。
2. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择含 manifest.json 的文件夹。
4. 安装后刷新已打开的课堂档案页面，并把插件固定到工具栏。
5. 自行登录腾讯会议，打开纪要，点击原页面的复制按钮。
6. 点击插件，读取已复制纪要，核对全文后点击「准备存档」。也可直接粘贴。
7. 在 mooodle.lovable.app 登录教师账号，选择学生和课节，打开课堂评分。
8. 点击「导入会议纪要」，核对课节与全文，选择追加或替换，再点原有保存按钮。

插件不接收腾讯会议密码、Cookie 或课堂档案登录令牌，不读取录制视频，不调用 AI。仅用户主动读取剪贴板；请核对复制内容，避免误导入其它剪贴板文字。草稿存放在 chrome.storage.local，不同步云端，24 小时后拒绝导入并在下次打开/请求时清除，可随时手动清除。真实腾讯会议纪要读取需在用户本机验证。
