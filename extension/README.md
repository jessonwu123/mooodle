# 腾讯会议纪要存档

> v1.2.1：在插件中保存 mooodle 教师账号密码后，打开插件自动登录并读取当日课次，无需打开 mooodle 页面；登录成功、自动登录和登录失败都有明确提示；存档前仍需在插件内确认。

1. 解压 ZIP。
2. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择含 manifest.json 的文件夹。
4. 安装后刷新已打开的课堂档案页面，并把插件固定到工具栏。
5. 首次使用：在顶部「mooodle 账号」填写教师账号和密码，点「保存并登录」。登录成功时状态栏显示「已登录 mooodle」并变为青色，账号栏标题变成「已登录 · mooodle 账号：xxx」；账号或密码错误时显示红色原因，账号栏保持展开。
6. 以后打开插件会自动登录，状态栏显示「已自动登录 mooodle」并直接读出当天课次；登录失效时显示红色原因，重新填写密码即可。
7. 自行登录腾讯会议，打开纪要，点击原页面的复制按钮。
8. 点击插件「读取标题」，核对左上角课堂名称，可直接修改为学生/课堂关键名字；点击「读取已复制纪要」并核对全文。
9. 日期默认北京时间当天，可修改；点击「匹配当日课次」优先匹配学生/课堂名字，忽略大小写、空格和标点；多个候选须手动选择。
10. 点击「存入选定课堂总结」，在插件确认正确日期、时间、学生后追加并保存，不改已有评分；该课节若还没有评分，需先到学生档案评好分。
11. 当前课堂评分按学生+日期保存。同一学生同日多课时禁止插件直接保存，需到学生档案核对后手动处理。没有关联学生档案的班课不会列入存档选项。
12. 原有「仅准备纪要」及课堂评分内「导入会议纪要」仍可用。标题读取选择器需在真实腾讯会议页面验证，读错时手动修改。正式网站必须先更新发布才能使用最新版插件的读取与存档接口。

密码只保存在本机浏览器插件的本地存储中，不上传、不同步；不用时可点「清除账号」。插件不接收腾讯会议密码或 Cookie，不读取录制视频，不调用 AI。仅用户主动读取剪贴板；请核对复制内容，避免误导入其它剪贴板文字。草稿存放在 chrome.storage.local，不同步云端，24 小时后拒绝导入并在下次打开/请求时清除，可随时手动清除。真实腾讯会议纪要读取、教师课表读取及课堂总结保存回读需在用户本机验证。
