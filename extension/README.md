# 腾讯会议纪要存档

1. 解压 ZIP。
2. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择含 manifest.json 的文件夹。
4. 安装后刷新已打开的课堂档案页面，并把插件固定到工具栏。
5. 自行登录腾讯会议，打开纪要，点击原页面的复制按钮。
6. 点击插件「读取标题」，核对左上角课堂名称，可直接修改为学生/课堂关键名字；读取已复制纪要并核对全文。
7. 点击「连接 mooodle」，在连接页面登录教师账号并点击「允许本次插件连接」。已有登录状态无需重输密码；页面可留在后台，插件不保存账号密码，不读取令牌。首次使用及刷新连接页面后需再次允许连接。
8. 返回腾讯会议打开插件，日期默认北京时间当天，可修改，点击「匹配当日课次」。优先匹配学生/课堂名字，忽略大小写、空格和标点；不根据通用科目或拼写近似猜测。多个候选须手动选择。
9. 点击「存入选定课堂总结」，在 mooodle 确认正确日期、时间、学生后追加并保存，不改已有评分。若还未有评分，打开评分窗口，纪要预填，需核对评分后保存；不自动伪造评分。
10. 当前课堂评分按学生+日期保存。同一学生同日多课时禁止插件直接保存，需到学生档案核对后手动处理。没有关联学生档案的班课不会列入存档选项。
11. 原有「仅准备纪要」及课堂评分内「导入会议纪要」仍可用。标题读取选择器需在真实腾讯会议页面验证，读错时手动修改。正式网站必须先更新发布才能使用新版连接页面。

插件不接收腾讯会议密码、Cookie 或课堂档案登录令牌，不读取录制视频，不调用 AI。仅用户主动读取剪贴板；请核对复制内容，避免误导入其它剪贴板文字。草稿存放在 chrome.storage.local，不同步云端，24 小时后拒绝导入并在下次打开/请求时清除，可随时手动清除。真实腾讯会议纪要读取需在用户本机验证。
